# 文档治理

**当前事实**：以源代码、`package.json`、`manifest.json`、`README.md` 和根 `docs/` 中的精简指南为准。
**归档**：旧的 v1.x 逐版过程记录、白板补丁说明、重复文档已从本次精简 ZIP 移出；原始 ZIP 作为回溯存档。
**历史**：历史的测试结果不能自动代表 v1.18.4 当前质量；新版本需重新运行相应测试与打包。

新增文档必须回答明确的维护问题；不要为每次小改动生成重复计划、测试、总结文件。
`docs/releases/<版本>/` 仅记录该版本真实提交范围和验证状态；没有运行过的验证必须明确写为“未验证”。
旧文档需要引用时可使用 Git 历史，不应回填到当前源码目录。
