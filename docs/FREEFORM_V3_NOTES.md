# Think OS Freeform Layout V3

本增量包必须在 V1、V2 增量包之后覆盖到项目根目录。本版不删除任何文件。

## 本版完成内容

1. 自由布局编辑态增加卡片选中状态与明确的高亮边框。
2. 选中卡片后可执行：
   - 置顶：更新当前 Layout 中该 ViewInstance 的 zIndex；
   - 锁定 / 解锁：锁定后禁止拖动和缩放；
   - 折叠 / 展开：折叠状态按 Layout 独立保存，不修改 ViewInstance 全局配置；
   - 从当前布局移除：仅解除 Layout 与 ViewInstance 的关系，保留视图配置。
3. 锁定、折叠、层级继续归属于 Layout.viewPlacements，不进入业务 View 配置。
4. 折叠时只使用紧凑视觉高度，保留用户原始 width / height；再次展开可恢复原尺寸。
5. 点击画布空白处取消选择；拖动开始时自动选中对应卡片。
6. 自由布局工具栏增加：
   - 添加已有视图；
   - 创建新视图并自动加入当前布局；
   - 重置当前布局到所选默认模板。
7. 自由布局中的删除按钮改为“仅从当前布局移除”，并增加二次确认；普通 list / grid 模式保持原来的全局删除行为。
8. 增加两种默认模板：
   - balanced：均衡排布，按各 View 推荐尺寸顺序装箱；
   - focus：焦点 + 网格，第一个 View 横跨首行，其余 View 从下一行排布。
9. 设置页切换模板时会明确提示并清空旧 placement，避免新模板与旧坐标混用。
10. 已存在自定义 placement 时，新加入的 View 自动追加到现有画布下方，避免覆盖用户手动摆放的卡片。
11. 窄屏或粗指针触控设备自动降级为普通列表，禁止自由布局编辑，避免拖动与页面滚动冲突。
12. 置顶算法处理相同 zIndex 的情况；已经唯一处于最上层时不会产生无意义写入。
13. 自由布局模型单测由 9 项扩展到 13 项，覆盖模板、折叠视觉高度、置顶和未知模板回退。

## 覆盖方式

1. 确保已经依次应用 V1、V2。
2. 备份当前项目。
3. 将本压缩包解压到项目根目录。
4. 保留压缩包目录结构，覆盖同名文件。
5. 不需要删除任何文件。

## 验收步骤

1. 打开自由布局，点击“编辑自由布局”。
2. 点击任意卡片，确认出现选中边框与“置顶 / 锁定 / 折叠”操作。
3. 点击锁定，确认拖动手柄变为禁用且右下缩放手柄消失；解锁后恢复。
4. 点击折叠，确认卡片缩为标题栏高度；重新展开后恢复原来的用户尺寸。
5. 将两个卡片重叠，点击底层卡片后执行“置顶”，重新加载插件后确认层级仍保持。
6. 点击卡片删除按钮，确认提示为“仅从当前布局移除”，且视图仍可从添加下拉框中重新加入。
7. 在工具栏选择一个已有视图并添加，确认新卡片出现在现有内容下方而不是覆盖已有卡片。
8. 新建一个视图并加入布局，确认创建和关联完成。
9. 在布局设置中切换“均衡排布 / 焦点 + 网格”，确认提示重置；焦点模板下第一个视图横跨首行。
10. 将 Obsidian 面板缩到 760px 以下，确认自动显示列表且编辑按钮不可用。
11. 恢复桌面宽度，确认自由布局坐标、尺寸、锁定、折叠和层级仍保持。

## 原项目现有验证限制

项目完整 TypeScript 检查仍存在原项目已有的基线错误，主要是旧 MUI 兼容回调的 implicit any、部分 QuickInput / AI / Excel 类型问题。本版新增的 FreeformCanvas、FreeformLayoutItem、LayoutRenderer、ModulePanel 和 freeformLayout 领域逻辑均通过 Vite 的 TypeScript 转换与生产构建。

原项目 package.json / package-lock.json 仍存在 webdriverio 版本解析问题。本次继续使用隔离的最小依赖环境完成构建和测试，未修改项目依赖文件。
