# Goal Center MVP16：扁平化目标 × Block 预设表

## 变更背景

上一版恢复了“目标 × Block 预设表”，方向是对的：行是目标，列是 Block，单元格是该目标下该 Block 的多个预设。

但上一版单元格使用了卡片样式：表格里再嵌套圆角卡片、状态标题、说明文字和点击提示。实际效果变成“格子套格子”，行高过大，信息显示不全，也不够简洁。

本版改为扁平矩阵：保留表格结构，移除单元格卡片。

## 设计结论

目标中心需要的是一张可扫视的矩阵，而不是一堆卡片。用户在这个页面要完成三个动作：

1. 快速判断某个目标 × Block 是否已经有预设。
2. 快速看到默认预设或前几个预设名称。
3. 点击单元格进入管理，不在表格内塞完整编辑信息。

因此本版的 UI 原则是：

- 表格就是表格，不再在单元格里放卡片。
- 单元格只显示最小必要信息。
- 完整预设管理放在点击后的编辑面板中。
- 继承默认的单元格只显示“默认 +”，不显示长说明。
- 有预设的单元格显示预设名称，多预设时显示“前两个名称 + 数量”。

## 新的信息结构

```text
行 = 目标
列 = Block / 记录类型
单元格 = 目标 × Block 的预设入口
```

单元格显示规则：

```text
无预设     默认  +
1 个预设   预设名
2 个预设   预设 A / 预设 B
3 个以上   预设 A / 预设 B    +N
隐藏       隐藏
异常       异常 + 数量
```

完整预设名称通过鼠标悬停 title 查看；点击单元格进入编辑面板查看和管理全部预设。

## 为什么这样更简洁

原来的卡片式单元格同时显示：

- 状态名
- 预设名
- 继承说明
- 隐藏数量
- 点击管理提示
- 圆角边框和背景

这些信息在矩阵中重复出现几十次，会让页面密度过低。

新版单元格只保留：

- 当前状态
- 预设摘要
- 可点击入口

矩阵变回“扫一眼就知道哪里有配置”的工具。

## 保留的能力

本版没有删除你的核心能力：

- 保留目标 × Block 表格。
- 保留一个单元格多个预设。
- 保留继承 Block 默认记录方式。
- 保留隐藏记录类型。
- 保留异常检测。
- 保留点击单元格后新增、编辑、复制、删除、设默认预设。

变化只发生在展示层：从“卡片单元格”改为“扁平文本单元格”。

## 具体改动

### 1. 移除单元格卡片

旧版每个单元格内部是一个带圆角、边框、背景、三行文字的按钮。

新版每个单元格是一个扁平按钮，直接铺满 `td`，不再额外画卡片边框。

### 2. 缩小行高

旧版单元格 `minHeight` 为 72px。

新版单元格 `minHeight` 为 42px。

这让表格可以一次显示更多目标，减少滚动。

### 3. 减少单元格文字

旧版继承默认时显示：

```text
默认
继承默认记录方式
点击管理 / 新增
```

新版显示：

```text
默认    +
```

有预设时直接显示预设名，不再显示状态说明。

### 4. 状态从大面积卡片改成左侧细线和淡背景

有预设、异常、隐藏等状态仍然可区分，但不再使用大块圆角卡片。

### 5. 简化顶部说明

`GoalTemplateSection` 不再使用说明卡片，只保留一句简短说明。
