# Think OS 文档入口

`docs/` 是 Think OS 唯一的实质文档目录；项目根目录只保留标准入口 `README.md`。旧 `doc/` 目录已并入这里，禁止重新创建。

## 当前事实（active truth）

- `ARCHITECTURE.md` — 当前模块边界与依赖方向。
- `RECORD_MODEL.md` — Canonical Record、Record Presentation、Template 与 Field 语义。
- `TESTING_RELEASE.md` — 本地验证、CI 与发布检查。
- `CSS_DESIGN_SPEC.md` — 当前 UI / CSS 设计合同。
- `UI_REDESIGN_PLAN.md` — UI 重构阶段与当前进度。
- `DEVELOPMENT_GUARDRAILS.md` — 防止架构再次发散的开发规则。
- `DOCUMENT_GOVERNANCE.md` — 文档归档与目录治理规则。

## 版本实施

- `releases/1.4.0/` — 1.4.0 Record Presentation Contract + Whiteboard Visual Cleanup 的计划、实施结果与测试报告。

## 专项文档

- `testing/` — 测试体系、命令、真实数据/E2E 规范。
- `reports/` — 仍需要随当前源码携带的专题报告。
- `history/` — 历史 Whiteboard 基线、旧 PATCH 说明、旧实施结果与迁移资料；仅用于追溯，不是当前接口。
