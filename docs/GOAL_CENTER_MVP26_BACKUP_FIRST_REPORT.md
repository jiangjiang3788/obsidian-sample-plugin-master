## 关于“目标主线 + 主题二级维度”

它不是把主题重新做成模板系统，也不是让主题重新决定表单。

正确含义是：

```text
目标 = 第一层统计与管理主线
主题 = 目标下面的分类 / 来源 / 图标 / 细分维度
```

例如：

```text
#照顾好自己
  健康/睡眠
  健康/心情
  健康/姨妈

#强健身体
  健康/运动
  健康/身体
```

以后视图可以优先回答：

```text
我这个目标整体做得怎样？
```

再继续展开：

```text
这个目标里面，哪些主题贡献最多？睡眠、运动、心情分别怎样？
```

所以它对应的不是“旧主题模板管理”，而是视图和统计里的二级分组。
