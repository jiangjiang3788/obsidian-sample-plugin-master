# MVP19：主题归类到目标 + 目标矩阵复用主题表格 UI

## 背景
上一版迁移逻辑把无法识别目标的主题路径当作目标创建，结果会把“健康/运动”“工作/设计”这类主题直接变成目标。这不符合目标中心的新模型。

新的模型是：

- 目标：我要追踪什么。
- 主题：表单来源、图标、颜色、领域路径。
- Block：记录类型。
- 预设：目标 × Block 单元格里的一个记录方式。

因此迁移应当是“主题归类给目标，目标使用主题原来的表单”，而不是“主题变目标”。

## 本版修改

### 1. 迁移逻辑改为主题归类
新增 `themeGoalMap`：

```ts
{
  "健康/运动": "#强健身体",
  "健康/睡眠": "#照顾好自己",
  "健康": "#照顾好自己"
}
```

key 可以是：

- 完整主题路径，例如 `健康/运动`
- 根主题路径，例如 `健康`
- themeId

匹配规则：

1. 优先使用用户手动归类。
2. 没有手动归类时，使用旧模板里明确写死的 `目标:: #xxx`。
3. 再没有时，从旧记录里的模板 ID 反推目标。
4. 仍然没有时跳过，不再把主题路径创建成目标。

### 2. 迁移 UI 改为用户可操作
位置：

```text
设置 → 目标中心 → 迁移
```

新增表格：

```text
主题 | 归到目标 | 表单数 | 建议
```

用户可以直接把某个主题填到目标，例如：

```text
健康/运动 → #强健身体
健康/睡眠 → #照顾好自己
工作/设计 → #工作质量
```

也可以在顶部按根主题快速归类，例如：

```text
健康 → #照顾好自己
工作 → #工作
电脑 → #软件系统
```

子主题会继承父级归类，除非子主题自己填了目标。

### 3. 不再无脑清空所有旧主题模板
迁移时只清理已经迁移成功的 override。

如果还有未归类的主题模板，它们会留在旧列表里，避免数据丢失。

### 4. 目标 × Block 预设表复用原主题表格视觉
目标矩阵 UI 改成和原来的主题矩阵一致的风格：

- 左侧路径列使用紫色分组胶囊。
- 状态列使用连续色块。
- Block 单元格使用原来的小圆角色块。
- 继承默认：绿色勾。
- 有预设：紫色编辑图标。
- 多预设：紫色数字。
- 禁用：红色叉。
- 异常：黄色感叹号。

不再使用之前那种大格子、卡片套卡片的设计。

## 用户路径

### 迁移主题表单

1. 进入 `目标中心 → 迁移`。
2. 在“归到目标”列里填写主题对应的目标。
3. 点击“迁移已归类主题表单”。
4. 迁移后进入“预设表”，查看目标 × Block 单元格。
5. 点击单元格管理多个预设。

### 使用迁移结果

例如：

```text
健康/运动 → #强健身体
健康/睡眠 → #照顾好自己
```

迁移后：

```text
#强健身体 × 打卡 → 运动打卡
#照顾好自己 × 打卡 → 睡眠打卡
```

主题不会成为目标，而是成为该预设的表单来源和默认主题值。

## 验收标准

1. 迁移 UI 不再提示“识别不到就用主题路径生成目标”。
2. 未归类主题不会被创建为目标。
3. 只有被归类、或旧记录里明确能识别目标的主题表单才迁移。
4. 迁移后目标 × Block 表格中出现对应预设。
5. 目标矩阵 UI 视觉接近原主题矩阵。
6. 已迁移 override 被清理，未迁移 override 保留。
