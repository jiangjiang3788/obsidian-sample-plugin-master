# Goal Center MVP25：旧记录改写预览 + 迁移进度表

## 本版目标

继续把系统从旧 Theme × Block 模板迁移到 Goal × Block × Preset 主链路。
本版重点不是再改表单 UI，而是让用户在 UI 里能看懂旧记录改写进度：哪些旧记录可以自动改、哪些旧记录还没有对应的新目标预设。

## 本版完成

1. 新增旧记录改写预览：显示待改写、可自动改写、未匹配、新预设映射数。
2. 迁移页展示旧记录样例：记录标题、旧模板 ID、是否可改写、将写入目标。
3. 增强旧记录改写逻辑：优先使用已经迁移出的 GoalTemplate.defaultValues.legacyOverrideId 映射；如果旧 override 还没有清理，也可从迁移计划补充映射。
4. 继续保留用户思维：不需要跑脚本；仍然在“目标中心 → 迁移”里点按钮完成。

## 设计判断

- 主题仍然保留在预设表单中，作为默认主题与统计维度。
- 主题不再是模板选择器，也不再自动变目标。
- 旧记录改写只改元数据：模板来源、模板ID、目标ID、目标、核心Block；不改正文。
- 没有匹配到新预设的旧记录不会强行改写，避免写错目标。
