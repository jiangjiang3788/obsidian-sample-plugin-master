# GOAL_CENTER_MVP21：目标预设表格化 + 主题可见但不主导

## 本版结论

本版围绕三个产品判断落地：

1. **目标是主线**：目标负责“我要追踪什么”。
2. **主题不再创建成目标**：主题只归类到目标，作为表单默认值、图标、颜色和统计维度。
3. **主题需要保留可见**：不是因为它还要决定模板，而是为了避免迁移后历史语义丢失。旧主题表单迁移成目标预设后，表单里仍能看到主题。

最终模型：

```text
目标 × Block = 多个记录预设
记录预设 = 旧主题表单的承接位置
主题 = 记录预设的表单默认主题 / 统计维度 / 图标颜色 metadata
```

## 我对“表单中是否需要主题”的判断

主题**需要保留，但不应该成为必填主实体**。

原因：

- 你的旧数据里，主题承载了大量真实分类语义，例如“健康/运动”“健康/睡眠”“生活/家务”。
- 如果迁移到目标后完全隐藏主题，你会感觉数据被吞了，后续热力图、按主题统计、图标显示也会断层。
- 但主题不应该再决定模板。模板由“目标 × Block × 预设”决定。

所以本版把主题降级为：

```text
表单默认主题（可选）
```

它的作用是：

```text
1. QuickInput 打开预设时自动带出主题
2. 表单字段里仍能看到主题
3. 输出模板仍能写出 主题:: xxx
4. 后续统计可以做 目标 → 主题 → Block
```

如果某个新预设不需要主题，可以不指定。

## 本版已完成改动

### 1. 目标下多个表单改为表格

文件：

```text
src/features/settings/goalTemplates/GoalTemplateEditorModal.tsx
```

原来是下拉选择当前预设，用户看不到这个目标 × Block 下到底有多少个表单。

现在改成表格：

```text
名字 | 主题 | 周期 | 保存文件 | 标题 | 默认 | 顺序
```

点击表格行即可切换正在编辑的预设。

### 2. 预设编辑器新增“表单默认主题”

文件：

```text
src/features/settings/goalTemplates/GoalTemplateEditorModal.tsx
```

保存预设时会同步写入：

```text
defaultValues.themePath
defaultValues["主题"]
表单字段 themePath / 主题 的 defaultValue
```

这样 QuickInput、输出模板、统计都能读取主题。

### 3. 迁移时强制保留主题字段

文件：

```text
src/core/goal/themeOverrideMigration.ts
```

旧主题模板迁移成目标预设时，如果字段里没有主题字段，会自动补齐：

```text
主题 / themePath
```

并把旧主题路径作为默认值。

### 4. QuickInput 不再允许在表单内新建目标

文件：

```text
src/app/ui/components/QuickInputEditor/QuickInputEditorContainer.tsx
src/app/ui/components/QuickInputEditor/components/GoalSelector.tsx
```

创建子目标应该去“目标管理”，不应该在记录表单里顺手创建。

本版已移除 QuickInput 里的快速新建目标入口。

### 5. QuickInput 选择预设后同步主题

文件：

```text
src/app/ui/components/QuickInputEditor/QuickInputEditorContainer.tsx
```

当预设默认主题写入表单后，会自动同步顶部当前主题，避免出现：

```text
表单字段是 健康/运动
顶部主题还是空 / 另一个主题
```

### 6. 周期继续归属预设

文件：

```text
src/app/ui/components/QuickInputEditor/QuickInputEditorContainer.tsx
```

周期从当前记录预设读取，不再从目标读取。

## 当前 MVP 验收口径

本版 MVP 重点不是把所有历史数据一次改完，而是先把交互方向拉正：

```text
1. 目标下多个表单要能看见
2. 多个表单用表格，不用下拉隐藏
3. 主题还在表单中可见
4. 主题不再是目标，也不再决定模板
5. 子目标不在记录表单里创建
```

## 设计原则

```text
目标负责追踪对象
Block 负责记录类型
预设负责表单与输出
主题负责分类、图标、颜色、统计维度
```

主题不是废弃，而是降级。
