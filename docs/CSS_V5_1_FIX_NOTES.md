# Think OS CSS V5.1 修正版

## 修复内容

1. 修复完整项目包内中文文档路径被写成 `#Uxxxx` 的问题。
2. 恢复正式 HTML 文档根目录为 `文档/`，与 README、文档生成脚本和验证脚本保持一致。
3. ZIP 使用 UTF-8 文件名标记，中文目录和文件名保持 NFC 规范化。
4. 快捷输入改为单一面板结构：
   - Obsidian Modal 本身是唯一 Surface；
   - 内层 `think-modal--quick-input` 仅承担结构，不再绘制第二张卡片；
   - 外层和内层均不使用面板投影；
   - 继续使用 CSS V5 的背景、边框、文字、Accent、输入框和状态 Token；
   - 桌面面板按内容居中，最大高度受视口约束，不再生成大面积空白外壳；
   - 移动端继续保留安全区、软键盘和 Sticky Footer 适配。

## 验收标准

- 项目中不存在 `#U4e00` 形式的路径。
- `文档/index.html` 和 `文档/_资源/` 能以真实中文路径访问。
- 快捷输入只显示一层面板边框。
- 快捷输入面板及其内部结构不存在 box-shadow。
- 快捷输入颜色仍全部来自 `--think-*` / Obsidian 语义 Token。
