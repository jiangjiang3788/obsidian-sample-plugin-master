# Goal Center MVP24：预设表内联编辑 + QuickInput 字段显示修复

## 本版核心结论

本版继续沿用你的判断：目标是主线，主题不再作为旧模板系统单独管理；主题只作为“目标 × Block 预设”的默认分类、图标和统计维度保留。

本版主要修复三个问题：

1. **目标下多个表单不再出现“表格 + 下方重复设置”的双重配置。** 现在名称、主题、周期、保存文件、标题、默认、顺序都直接在预设表格里编辑。
2. **修复迁移主题默认值被 `{{goal.themePath}}` 覆盖的问题。** 迁移后的预设会保留真实来源主题，例如 `健康/睡眠`，不会再被占位符覆盖。
3. **QuickInput 按预设字段显示表单。** 主题字段不再被当作系统字段强制隐藏；如果预设里有主题字段，快速输入中会正常显示。

## 本版修改

| 模块 | 修改 |
|---|---|
| 预设编辑器 | 目标 × Block 单元格里的多个预设改为表格内联编辑。 |
| 预设编辑器 | 删除下方重复的“预设名称 / 表单默认主题 / 周期 / 顺序 / 默认”设置块。 |
| 预设编辑器 | 删除下方重复的“保存到文件 / 写入标题下”设置块，改为在表格列中设置。 |
| 迁移逻辑 | 旧主题模板字段里的 `{{goal.themePath}}` 不再覆盖真实主题路径。 |
| QuickInput 字段渲染 | `themePath / 主题` 不再被系统上下文字段过滤掉；预设中配置了主题字段就显示。 |
| 说明 | 主题仍然不是目标，也不是旧模板管理入口，只是当前预设的默认分类和统计维度。 |

## 验收方式

1. 打开目标中心的目标 × Block 预设表。
2. 点击一个目标 × Block 单元格。
3. 应看到预设表格，第一列是名字，后面是主题、周期、保存文件、标题、默认、顺序。
4. 点击某个预设行，可以直接在该行修改这些设置。
5. 下方只保留“表单字段”和“输出格式”等真正属于表单内容的高级设置。
6. 打开 QuickInput，选择有迁移预设的目标和记录类型。
7. 如果该预设中有“主题”字段，QuickInput 应显示主题字段。
8. 保存位置应按预设的保存文件和标题计算。
