# Think OS：从命令面板下载并更新开发版

## 新增命令

在 Obsidian 的命令面板（手机端和桌面端均可使用）搜索：

**`更新：从 GitHub 下载并安装最新开发版`**

命令 ID：`think-update-github-dev-build`

- 执行后直接查询 GitHub `main` 分支最新 SHA，下载对应的 `main.js`、`styles.css`、`manifest.json`，无需先打开设置页面。
- 与设置页的更新按钮复用同一实现：检查远端插件 ID、校验文件、读取并备份本地文件、写入后校验、失败回滚。
- 成功后显示版本/SHA 和重启提示。**必须完全退出并重新打开 Obsidian**，新版本才会加载。
- GitHub API 403 限流时会失败提示，且在尚未开始写入时不会改变本地文件。
- 更新器只允许同时执行一次安装；设置按钮与命令同时触发时，后发起的一次会明确提示“正在下载或安装”，避免并发写入/回滚破坏插件。
- 仍保留设置页面的原按钮及“已检查 SHA”回退入口；命令本身始终获取 `main` 最新 SHA，不默默安装旧版本。

## 与诊断记录的关系

更新操作复用 `traceThinkOperation('github.install', ..., 'updates')`，会记录操作耗时、成功或失败状态；不记录下载内容或用户笔记。

## 验收建议

1. 在命令面板中搜索上述命令，观察开始提示。
2. 正常下载后确认成功通知和重启提示；退出并重新打开 Obsidian。
3. 在下载期间通过设置按钮再次发起，确认第二次被拒绝，不会重复下载或相互回滚。
4. 网络失败或 GitHub 返回限流错误时确认本地插件文件不变。

注意：源码包未包含 `node_modules` 与已编译的插件文件。在完成依赖安装、编译和真机测试前，不应把它当作可直接安装的正式构建。
