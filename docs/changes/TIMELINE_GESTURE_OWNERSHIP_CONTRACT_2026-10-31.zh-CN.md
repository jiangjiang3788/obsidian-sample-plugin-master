# Think OS 时间轴：滚动与手势责任边界审计（候选修改）

日期：2026-10-31  
状态：**源码候选，未正式构建、未真机验收，不可认定为正式修复版本**  
基线：Think OS 1.18.4 源码。`manifest.json`/`package.json` 的现有版本号未作为正式发布进行变更。

## 一、从真实 iPhone 记录能确认什么

- 第一轮（schema 1，6 次）及第二轮（schema 2，13 次）多数记录表明：时间轴本身可以独立滚动，外层不一定同步移动。这**不能**证明外层没有竞争。
- 2026-10-31 12:49 左右的最新 schema 2 记录共 24 次。**第 1 次**从 `timeline-statistics-header` 开始，`Timeline viewport` Y 位移 **+33px**，另一个有 2261px 垂直可滚动空间的父 `div` Y 位移 **+393px**，其中父层抬手后 **+285px**。**确证同一次触摸出现了双层纵向滚动**。
- 同一轮还存在纯纵向触摸时横向峰值偏移（最高数百像素），以及触摸停止后纵向/横向位置明显变化。需要区分原生惯性、旧惯性尚未结束和程序性写入；不能凭位移单独宣称是哪一处代码造成。
- 该日志没有记录时间轴的起始绝对 `scrollTop` 或所有程序性写入调用栈。因此“双层是否因到达内层边界而链式传递”是**最符合证据的机制，但尚未完全证明触发条件**。初期源码的 `overscroll-behavior: contain` 已存在；不能误称以前没有配置它。
- 星期日可达性属于滚动停靠和边界问题，不是缺少星期日列。本候选不会修改七天结构、列宽、统计栏或视图类型。

## 二、焦点层与操作权（适用于一次手势，不是 DOM z-index）

| 层级 | 可以做什么 | 不应做什么 | 触摸起点范围 |
| --- | --- | --- | --- |
| Obsidian / Think OS 主页面 `div` | 从时间轴外开始时正常纵向滚动 | 抢时间轴内起始的手势；一边让内层 Y 动，一边自身 Y 动 | 时间轴之外 |
| `.think-module` / `.module-content` | 展示布局、内边距、标题、折叠 | 为时间轴额外实现横向惯性或识别左右翻页；本轮不修改通用模块 CSS | 模块框架 |
| `.timeline-view-wrapper` **焦点与滚动层** | 统一分配触摸意图；Y 原生滚动，X 受控平移；隔离父层 JS 触摸手势 | 横滑时擅自把 Y 拉回旧值；将纵滑交由外层 JS 处理 | 整个时间轴，含统计栏和网格 |
| `.timeline-sticky-header` | 固定展示统计和日期；触摸交给同一时间轴 | 自己再建一个独立滚动器 | 顶部统计栏/日期栏 |
| `.day-column-body` | 单击、双击、空白处长按建区间；未完成长按前让时间轴处理滑动 | 自己直接改 `scrollTop/Left` 或把普通滑动认作新建任务 | 时间网格 |
| `.timeline-task-block` / 边缘拖动柄 | 点击选中、长按后专属编辑、电脑边界拖动 | 普通手指划过就进入编辑；直接驱动页面滚动 | 时间块和拖动柄 |
| 双指缩放 `useTimelineZoom` | 当且仅当双指合法识别、未在时间拖动中时，修改缩放和 Y 定位 | 与单指 pan 同时处理同一触摸 | 同一时间轴上的两指 |
| “定位当前时间” `TimelineTimeAxis` | 显式双击时修改**所属时间轴**的 `scrollTop` | `scrollIntoView()` 让祖先容器一起滚动 | 时间尺交互 |
| 内置诊断 | **只读**记录触摸起点和滚动位移 | 调用 `preventDefault`、`stopPropagation` 或修改滚动位置 | 用户打开记录后 |

## 三、同一手势的唯一主导权

1. 从时间轴外开始：正常由 Obsidian / Dashboard 的原生页面滚动负责。
2. 从时间轴内部开始：时间轴拥有触摸焦点。事件仍先到任务子元素，但不再交给外层 JavaScript 横滑 / 手势识别器。注意 `stopPropagation` **不能**阻止浏览器的**原生**滚动链。
3. 单指移动未超过意图阈值：仅等待，不抢编辑，不平移任一轴。
4. 意图判为 Y：**WebView 在内层范围内负责原生 Y**；同一控制器只在检测到意外 X 漂移时恢复原有日期位置。内层 Y 边界的“可取消触摸”交由明确的边界守卫接管，剩余动量不得交给外层。
5. 意图判为 X：时间轴单一控制器更新 `scrollLeft`，手指结束就停；不得写 `scrollTop`，不得自动翻页或合成甩动惯性。
6. stationary long press 达到 520ms：对应时间块/空白格的编辑动作取得权限；普通滑动仍在长按前取消此候选。
7. 同一时间轴上的两个合法触点：缩放控制器接管，取消未确认的单指候选；已开始的时间拖动不能被悄悄转成缩放。
8. 主动定位当前时间只由用户的双击触发；诊断永远不取得滚动控制权。

## 四、这次改了什么（严格控制范围）

1. `src/shared/ui/timeline/TimelineAxisPan.ts`
   - 取消了 **X 横向拖动期间执行 `surface.scrollTop = current.top`** 的行为。这是源码中已确认的跨轴覆盖：旧的 Y 起点不是当前 Y 的合法目标。
   - 对从时间轴起始的触摸，在根组件**冒泡阶段**停止向外层 JS 手势识别器继续传播。捕获阶段/子节点逻辑、原生浏览器默认滚动不变。长按和缩放仍可在时间轴子组件内处理。
   - 对 Y 手势增加明确的 `edgeOwnedY` 边界转移状态：在 `touchmove` 可取消、且本次手指增量预计超出内层上下边界时，时间轴接管**这次触摸余下的 Y 位移**，夹紧到滚动边界（再往内反向拖仍可移动），不启动自制惯性，也不写祖先 `scrollTop`。
   - 继续使用 1.18.4 的严格横向意图判定、真实 `scrollLeft` 起点及无横向甩动模型；**没有调阈值**。
2. `test/unit/timelineAxisPan.test.ts`：更新横向不会修改 Y 的断言，新增时间轴内部 Y 不能交给父层 JS 监听器、Y 边界及反向进入等测试。
3. `scripts/testing/verify-timeline-safe-pan-offline.cjs`：新增“X 不覆盖 Y”“处于底部立即挡住外层”“离底部 25px 一次划越界时仍停在内层”的离线回归。
4. `scripts/testing/verify-timeline-ownership-contract-offline.cjs`：新增静态契约检查，保护单一时间轴滚动口、七天结构、程序性写入入口及诊断只读性。

**没有修改**列宽、星期顺序、任务数据读写、自动记录、外层所有通用模块样式、`useTimelineZoom` 缩放算法、更新命令、内置诊断面板。

## 五、仍有风险，不能对用户隐瞒

- iOS WebView 可能在第一帧之后把 `touchmove` 设为不可取消，或者在**抬手后的原生惯性阶段**继续出现滚动链。CSS `overscroll-behavior: contain` 和本次边界守卫可能未必完全拦住这种情况，必须真机测。**浏览器模拟通过不能保证 iOS 手感**。
- 现有日志只能看到位置变化，不能识别全部来源。`useTimelineZoom` 内有缩放专用 `scrollTop` 写入，`TimelineTimeAxis` 有明确双击后的 `scrollTop` 写入；目前没有证据表明它们一定引发那次约 1459px 的变化，所以未擅自重写它们。
- 阻止向外层 JavaScript 冒泡会让 Obsidian 从时间轴内部启动的宿主级“整页侧滑切换”失效；这是明确授权策略，但仍需测试宿主其他功能。时间轴之外不受影响。
- 修改后的根控制器会在达到 Y 边界的单指移动期间短暂由 JavaScript 接管 Y。进入内层与离开边界的过渡手感，必须在 iPhone / Android 测试；若发僵，应回退这个单独机制而非继续叠加补丁。
- 当前工程不包含 node_modules 和已编译的 `main.js`/`styles.css`，无法完成正式构建/Jest/设备验证。本包是**候选源码，不是可安装插件**。

## 六、验收门槛（不给模拟测试替代真机）

- iPhone：从统计栏起始向上快速滑动至时间轴底部，外层页面不得同步移动；在空白网格反向拖回，不能卡死。
- iPhone：多次先上下、后左右、再上下，日期不能“弹回”，抬手不得出现巨大反向位移；周一至周日可以精准停住。
- iPhone：时间块轻划正常滚动；长按 520ms 之后的拖动才改时间；缩放与一指移动互斥。
- Android：重复同样场景，特别确认手势取消、触摸序列及滚动边界。
- 电脑：滚轮/触控板、鼠标时间块上下拖动柄、Alt+滚轮缩放、右键菜单正常。
- 所有设备：从时间轴**外部**起始，Think OS 页面仍能正常滚动。
- 若仍出现双层位移，先记录触摸事件 `cancelable` 状态和两层起始绝对 `scrollTop`，再判断是否需用其他浏览器适配；**不要再凭速度感继续调常数**。
