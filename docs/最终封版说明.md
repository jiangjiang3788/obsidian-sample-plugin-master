# 最终封版说明

最终质量入口：`npm run verify:ci`、`npm run gate`、`npm run build:release`。

V31 新增深度收敛封版入口：`npm run deep-refactor-final:gate`。

原则：不再强拆已经小而清晰的组件；新增功能先做 ownership 判断、语义复用检查和文件预算；完整本地验证通过后再发布或合并。

完整本地验证建议：

```bash
npm ci
npm run typecheck
npm run build
npm run test:unit
npm run gate
```

当前源码包不包含 `node_modules`，因此类型检查、构建和单测需要在本地安装依赖后执行。
