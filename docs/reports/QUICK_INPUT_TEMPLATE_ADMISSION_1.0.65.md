# 1.0.65 快捷录入模板准入与模板矩阵修正

## 产品规则

1. 创建快捷录入以 `recordTypeId + goalPath` 为唯一上下文。
2. 模板型记录创建必须命中 enabled 的直接 GoalTemplate；没有直接模板不打开该上下文的快捷输入面板，也不回退 RecordType 默认表单。
3. 命令只先确定记录类型。目标树中没有直接模板的祖先节点只负责导航，不写入 Goal context；只有真正配置模板的目标可以被选择并加载表单。
4. RecordType 模板仍是字段/持久化结构基底，用于合并 GoalTemplate，也可服务编辑回填；它不再是 create fallback。
5. 精力属于 direct capture，不受 GoalTemplate 准入限制。

## 模板矩阵

- 新增模板入口只存在于目标行，使用紧凑 `+` 按钮，不在空单元格重复添加按钮。
- `+` 按钮展开该目标尚未配置的记录类型，选择后直接进入模板编辑状态。
- 已配置模板单元格显示模板图标 + 名称；名称优先使用模板默认内容/任务内容，否则回退记录类型名称。
- 空单元格仅表示未配置，不再表示“使用默认模板”。
- 控件保持统一高度和无投影视觉规则。

## 回归重点

- Heatmap/视图入口带具体 Goal 且存在直接模板：目标自动选中并加载该模板。
- 入口带具体 Goal 但没有直接模板：Modal 在渲染前拦截并提示，不展示 Quick Input 内容。
- 命令入口：只能在具有该 RecordType 模板的目标分支中导航；祖先节点不误选，点击真实模板目标后才显示字段。
- 创建提交再次执行 direct-template 校验，避免 UI 绕过准入规则。
