# GOAL_CENTER_MVP28：旧记录深度扫描

## 版本目标

本版按迁移计划继续推进第 3 项：旧记录扫描。上一版已经完成数据审计，本版把旧记录拆成更细的扫描维度，让后续改写更安全。

## 本版完成

1. 新增 `buildThemeOverrideRecordDeepScan(settings, items, limit)`。
2. 迁移页新增「2. 旧记录深度扫描」。
3. 扫描旧记录是否属于：任务行内格式、块字段格式、混合格式、未知格式。
4. 展示字段完整度：目标、主题、核心Block、模板ID、模板来源。
5. 展示旧模板 Top：旧模板 ID、记录数、可改写数、未匹配数、目标。
6. 展示旧记录样例：记录标题、文件位置、格式、旧模板、目标/主题、改写状态。

## 设计判断

旧记录改写不能只看有没有 `模板来源:: override`。实际数据里可能同时存在：

- 任务行内 metadata，例如 `(模板ID::ovr_xxx)`；
- 块记录 metadata，例如 `模板ID:: ovr_xxx`；
- 混合格式；
- 已解析 item 里有 templateId，但原始文本形态不稳定。

所以先做深度扫描，再做批量改写，避免误改正文。
