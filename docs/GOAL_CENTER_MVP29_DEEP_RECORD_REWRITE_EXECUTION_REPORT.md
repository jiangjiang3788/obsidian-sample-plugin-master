# GOAL CENTER MVP29：旧记录深度改写执行

## 本版目标

继续推进主题表单迁移到目标预设后的数据收口。本版重点完成计划表第 14、15 项：旧记录改写与任务行改写，并把“块字段格式”的旧记录也纳入改写范围。

上一版已经能扫描旧记录，区分：

- 任务行内格式，例如 `(模板ID:: ovr_xxx)`、`(模板来源:: override)`；
- 块字段格式，例如 `模板ID:: ovr_xxx`、`模板来源:: override`；
- 混合格式；
- 未知格式。

本版在执行层补齐：不仅任务行能改，`<!-- start --> ... <!-- end -->` 块记录也能改。

---

## 本版完成内容

### 1. 深度改写旧记录

新增 ItemService 方法：

```ts
upsertItemGoalTemplateMigrationFields(itemId, fields)
```

它会根据记录类型自动选择写回方式：

| 记录类型 | 写回方式 |
|---|---|
| task | 修改当前任务行内 `(字段:: 值)` |
| block | 修改 `<!-- start --> ... <!-- end -->` 内的块元数据行 |

写回字段包括：

```text
模板来源:: goal-template
模板ID:: 新目标预设 ID
目标ID:: 新目标 ID
目标:: 目标路径
核心Block:: coreBlockId
主题:: 预设默认主题
```

### 2. 块记录改写

此前 `applyThemeOverrideRecordMigration()` 只调用 `upsertItemInlineFields()`，它适合任务行，但对块记录会把元数据塞到起始行，效果不理想。

本版新增块记录专用逻辑：

- 定位块起点和终点；
- 在块内部更新已有 metadata 行；
- 如果 metadata 不存在，则插入到 `内容::` 之前；
- 不移动用户正文。

### 3. UI 结果反馈增强

迁移页的旧记录改写按钮改为：

```text
3. 深度改写旧记录
```

执行后显示：

```text
更新总数
任务行更新数
块字段更新数
失败数
跳过数
未匹配数
```
