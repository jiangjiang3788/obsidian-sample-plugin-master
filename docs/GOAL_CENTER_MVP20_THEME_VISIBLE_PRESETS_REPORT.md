# GOAL_CENTER_MVP20：目标迁移主题归类 + 表单可见主题

## 版本目标

本版不再把主题创建成目标。迁移后的关系是：

```text
目标 = 我要追踪什么
主题 = 归类 / 图标 / 颜色 / 表单默认值
Block = 记录类型
目标 × Block 单元格 = 多个预设
预设 = 使用某个旧主题表单迁移而来的记录方式
```

用户在 QuickInput 表单中仍然能看到“主题”字段；选择迁移后的目标预设时，会自动带出这个预设来源主题，例如“健康/运动”。

## 验收路径

1. 设置 → 目标中心 → 迁移：把主题归类到目标，而不是把主题创建成目标。
2. 设置 → 目标中心 → 预设表：目标 × Block 表格单元格显示主题短标识。
3. 点击某个单元格：预设编辑器里能看到“表单默认主题”。
4. 打开 QuickInput：选择目标、Block、预设后，表单里仍有“主题”字段，并自动显示迁移前的主题路径。

## 设计判断

主题不是主模板轴了，但主题仍然是记录的重要信息。迁移后的系统应该是：

```text
目标决定我要追踪什么；
Block 决定我要记录哪类事情；
预设决定这个目标下这个 Block 的具体表单；
主题作为表单字段、图标、颜色和统计维度继续存在。
```
