发布流程

发布前检查以统一验证入口为准，避免各页面维护不同命令导致失真。

状态：当前有效最后更新：2026-05-14格式：HTML生命周期：长期

发布前主验证

npm run docs:index
npm run verify

如果要模拟 CI，使用：

npm run ci

验证入口含义

命令用途适用场景
npm run verify:fasttypecheck + gate + unit日常快速检查。
npm run verifydocs:index + typecheck + gate + unit + integration + build发布前主检查。
npm run verify:ci完整验证并检查文档索引是否同步CI 环境。
npm run ciCI 别名入口远端自动化。

发布步骤

  1. 确认 问题记录 无开放阻塞。
  2. 确认 技术债 无 P0 开放项。
  3. 运行 npm run verify。
  4. 确认 main.js、styles.css 和文档索引已更新。
  5. 更新 Changelog 和发布记录。
