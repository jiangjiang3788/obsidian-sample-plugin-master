实施计划：Phase B 脚本目录整理

本轮目标是整理 scripts/ 目录结构，而不是继续改业务逻辑。脚本按 gate、audit、docs、build、lib 分区，package scripts 保持原命令名不变。

状态：本轮完成优先级：P1最后更新：2026-05-14

修改目标

  • 让 scripts/ 不再把所有 gate、audit、docs、build 工具堆在根目录。
  • 保留 npm run gate、npm run build、npm run docs:index 等外部命令名，避免使用成本变化。
  • 把 gate 共享格式化工具抽到 scripts/lib/。
  • 更新 allowlist 路径和文档引用，避免脚本迁移后提示信息误导。
