模块职责

当前主要模块的职责边界说明，用于避免后续功能开发时再次把 app/core/platform/shared 混在一起。

状态：当前有效最后更新：2026-05-14格式：HTML生命周期：长期

核心职责边界

模块可以做不应该做
app组合 usecase、调用 core 服务、衔接 UI capability。不直接操作 Vault/Workspace；不放领域纯计算。
core定义领域类型、服务、port、规则和解析。不 import obsidian；不 import shared UI。
platform实现 Obsidian 相关 port、Modal 和插件设置页桥接。不承载业务规则。
features注册功能入口、组合功能 UI。不跨 feature 复用内部实现；公共逻辑下沉 core/shared。
shared提供通用 UI、hook 和工具。不依赖 app 内部动作；不 new platform modal。

新增代码放置判断

  • 和 Obsidian API 相关：优先 platform。
  • 可复用业务规则：优先 core。
  • 界面组件但无业务语义：优先 shared/ui。
  • 某个功能独有 UI：放对应 feature。
  • 跨 feature 复用的纯逻辑：不要互相引用，抽到 core 或 shared。
