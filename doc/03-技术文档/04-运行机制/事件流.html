事件流

记录 Obsidian 事件、用户事件和内部事件如何进入系统。

状态：建议模板 最后更新：2026-05-07 格式：HTML

事件来源

事件来源代表模块作用
Obsidian Vault 事件platform/events/VaultWatcher.ts、ObsidianEventsPort.ts监听文件变化、刷新索引或状态。
用户命令src/main.ts命令面板触发业务动作。
UI 事件features 中的组件按钮点击、表单修改、拖拽排序。
Timer 事件TimerService / TimerStateService开始、暂停、停止、写回。
诊断事件shared/debug、performanceMonitor收集日志和性能信息。

事件设计原则

  • 事件监听必须可释放。
  • 不要让 UI 组件直接承担复杂事件编排。
  • Vault 事件要防抖或控制重扫范围。
  • 事件触发的写入需要错误提示和回滚思路。
