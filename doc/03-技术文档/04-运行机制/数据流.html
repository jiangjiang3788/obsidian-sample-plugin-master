THINK OS DOCUMENT SYSTEM

数据流

说明数据从 Obsidian Vault、设置、输入和服务之间如何流动。

状态：建议模板 最后更新：2026-05-07 格式：HTML

主要数据源

数据源来源用途
插件设置loadData/saveData 与 SettingsRepository保存布局、字段、输入、AI、主题等配置。
Vault MarkdownObsidian 文件系统，经 VaultPort 读取/写入任务、记录、时间数据的主要载体。
运行缓存DataStore、TimerStateService、AI cache 等提升读取和计算效率。
用户输入QuickInput、Settings、Modal、Command触发记录、计时、配置变更。

典型写入链路

用户输入 / 命令
  -> feature UI / modal
  -> app usecase
  -> core service
  -> platform port
  -> Obsidian Vault / plugin data

数据设计原则

  • 设置数据要有默认值和迁移策略。
  • Vault 写入要避免覆盖用户已有内容。
  • 缓存不可信时要能重建。
  • AI 解析结果必须经过校验后再写入。
