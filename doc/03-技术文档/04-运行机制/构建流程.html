构建流程

说明从源码到 Obsidian 可加载文件之间的构建和检查链路。

状态：建议模板 最后更新：2026-05-07 格式：HTML

核心脚本

脚本作用
npm run dev启动 Vite 开发构建。
npm run build执行 Vite build，修 sourcemap，并复制 dist 到根目录。
npm run check运行 lint、typecheck 和 gate。
npm run gate运行全部架构门禁。
npm run test运行 Jest 测试。
npm run cicheck + gate + build。

构建产物

文件来源用途
main.jsdist/main.js 复制而来Obsidian 插件主脚本。
styles.cssdist/styles.css 复制而来Obsidian 插件样式。
manifest.json根目录维护插件元信息。

发布前最低检查

  1. npm run check
  2. npm run test
  3. npm run build
  4. 手动打开 Obsidian 验证关键命令和设置页。
