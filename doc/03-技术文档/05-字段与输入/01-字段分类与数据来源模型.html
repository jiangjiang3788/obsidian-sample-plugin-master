字段分类与数据来源模型

本页回答“每个字段的数据都是哪里来的”。字段先按角色分类，再用 FieldOrigin 记录来源，避免核心字段、文件字段、派生字段、extra 字段继续混在一起。

状态：当前有效最后更新：2026-05-21格式：HTML

字段分类定义

分类代表字段来源规则
核心字段 Coreid、type、title、content、editableText、rawSourceparser / normalizer记录成立所必需，不能由用户任意删除。
文件字段 Filefile.path、file.name、folder、header、created、modifiedObsidian file metadata / heading cache表示记录所在文件与位置，不参与业务语义推导。
语义字段 SemanticthemePath、categoryPath、tags、status、date、rating、image显式字段或字段语义映射用户真正关心的业务维度，名称可变，语义不可猜。
派生字段 DerivedrootTheme、leafTheme、dateMs、periodCount从显式字段计算只读，不写回 Markdown；必须记录 derived-from。
自定义字段 Extraextra.地点、extra.项目显式未知 KV没有 schema 时先进入 extra，但必须有 origin；不允许 parser 自动生成内容 alias。
历史字段 Legacytheme、旧 pintu、旧正文 alias旧数据兼容可读可迁移，默认隐藏，不作为新数据写入标准。

字段来源枚举

来源类型含义例子
markdown_task_kv任务行中的 (key::value)。(主题::工作/设计)、(地点::办公室)。
markdown_block_kvblock 内部的 key:: value。标签:: a, b、图片:: ![[x.png]]。
markdown_tag正文中的 Obsidian tag。#工作/设计。
markdown_heading记录所在标题。## 今日计划，只进入 header。
file_path文件路径或文件名。folder、file.path。
file_stat文件 ctime/mtime。created、modified。
template_default模板默认值。表单默认日期、默认状态。
derived从其他字段计算。rootTheme from themePath。
cache缓存字段恢复。读取 cache 时必须标注 cache version。
legacy_fallback旧版本兼容值。只允许读，不允许作为新写入路径。

字段来源数据结构

export type FieldOriginKind =
  | 'user_input'
  | 'template_default'
  | 'markdown_task_kv'
  | 'markdown_block_kv'
  | 'markdown_tag'
  | 'markdown_heading'
  | 'file_path'
  | 'file_stat'
  | 'derived'
  | 'cache'
  | 'legacy_fallback';

export interface FieldOrigin {
  fieldKey: string;
  rawKey?: string;
  value: unknown;
  origin: FieldOriginKind;
  sourcePath?: string;
  sourceLine?: number;
  derivedFrom?: string[];
  confidence: 'explicit' | 'derived' | 'legacy';
}

字段值来源矩阵

字段标准来源禁止来源备注
themePath显式主题语义字段：task (主题::)、block 主题::、或 semantic=themePath 的字段。header、文件夹、标题推断。筛选中的“主题”默认就是它。
rootTheme / leafTheme从 themePath split 派生。从 header split。只读派生字段。
headerObsidian heading cache。任何业务字段 fallback。只表示位置。
tags#tag、标签字段、多标签字段。从 theme/category 自动拆。多值层级字段。
extra.*显式未知 KV。parser 自动正文 alias、硬编码 extra registry。必须有 origin。
imageimage/multiImage 字段、旧 pintu 迁移。字段 key 等于 pintu 才显示图片。图片是字段类型，不是 key 特例。
