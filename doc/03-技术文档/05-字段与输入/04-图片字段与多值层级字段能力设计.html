图片字段与多值层级字段能力设计

本页把图片、多图、多选、标签、主题、分类统一成基础字段能力，避免继续用 pintu、rating 或固定字段名来承载图片和层级语义。

状态：当前有效最后更新：2026-05-21格式：HTML

设计目标

图片、多选、标签、主题、分类不应该是某几个固定字段名，而应该是基础字段能力。用户可以新增任意图片字段、多图字段、多选字段、层级路径字段、多标签字段。

图片字段值结构

export interface ImageValue {
  src: string;
  kind: 'vault' | 'wikilink' | 'url' | 'attachment';
  alt?: string;
  caption?: string;
  width?: number;
  height?: number;
}

type ImageFieldValue = ImageValue | ImageValue[];

层级字段统一模型

字段能力值语义例子筛选行为
path"工作/设计/道旗"themePath、categoryPath等于、包含父级、包含子级。
multiPath["工作/设计", "生活/健康"]多分类、多领域any / all / contains。
tag"#工作/设计"单标签标准化去 # 后比较。
multiTag["工作/设计", "项目/A"]多标签any / all / none。

UI 组件拆分

组件职责
ImageFieldInput输入、选择、粘贴、预览图片。
ImageFieldRenderer列表、卡片、详情里的统一图片展示。
PathFieldInput层级路径选择、快速创建子路径。
MultiTagFieldInput多标签选择、补全、去重、层级展示。
FieldPill不再判断 fieldKey === "pintu"，改为读取 field definition。

迁移策略

旧逻辑新逻辑兼容方式
pintu 字段显示图片semantic=image 的字段都显示图片。旧 pintu 注册为 legacy alias。
rating option 使用图片路径rating 和 image 分离。保留旧 rating 图片选项读取，但新建字段推荐 image。
标签只是 string[]multiTag 字段，支持层级与多值筛选。旧 tags 直接映射 semantic=tags。
主题/分类是固定字段path 字段 + themePath/categoryPath 语义。旧 theme/categoryKey 迁移为语义字段。
