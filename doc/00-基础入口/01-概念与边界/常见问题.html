为什么还要一个 HTML 文档系统？

因为这个项目已经包含功能、设置、AI、Timer、主题、架构 gate 等多类内容。普通 Markdown 容易散，HTML 页面更适合作为左侧导航清晰的项目驾驶舱。

旧 docs 和 html 怎么办？

先不要马上删除。当前建议是：正式入口迁移到 文档/；旧 docs/ 和 html/ 只作为资料来源。等新文档稳定后，再迁移仍有效的内容，其余归档。

新增一个功能要改哪些文档？

  1. 20-需求池.html：登记需求。
  2. 40-功能总览.html 或对应功能页：写设计。
  3. 61-文件地图.html：补涉及文件。
  4. 46-功能验收标准.html：写验收。
  5. 25-决策记录.html：记录关键选择。

什么时候使用评审中心？

当你准备做大改、接入新能力、重构模块、合并版本或发布时使用。评审中心不是说明书，而是判断“该不该做、能不能做、有没有风险”。
