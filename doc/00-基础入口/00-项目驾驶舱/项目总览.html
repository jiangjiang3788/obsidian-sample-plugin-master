项目总览

用一页说明 Think OS 的新产品方向、当前重定位阶段和核心阅读路径。

状态：重定位主线 最后更新：2026-05-13 格式：HTML

项目一句话

Think OS 是运行在 Obsidian 内的本地优先个人管理系统，用目标闭环把计划、任务、执行记录、总结复盘和统计反馈串成一条可复用的个人管理主线。

文档目标：先重新画清产品边界，再决定现有 QuickInput、Timer、Statistics、Block、View 等实现如何迁移到新主线。

当前项目画像

插件类型Obsidian 第三方插件，运行在本地 Vault 与 Markdown 工作流之上。
产品主轴目标 → 计划 → 任务 → 执行记录 → 总结复盘 → 统计反馈 → 调整。
现有基础已有输入、计时、视图、统计、主题、AI 和设置能力，但这些能力需要围绕目标闭环重新组织。
当前阶段第一批只更新文档信息架构和页面职责，不修改插件代码。
