顶层目录

目录用途维护规则
src/app应用编排、usecase、runtime、bootstrap、capability。不得直接承载 Obsidian API；不得越过 core public 入口深度依赖 core 内部。
src/core领域类型、服务、port、解析、AI 配置、Goal/Cycle/Record 契约。保持平台无关，core 内部不 import @core/public。
src/platformObsidian API、Modal、Vault、SettingTab 等适配。平台依赖集中于此。
src/featuressettings、timer、quickinput、aiinput 等功能入口。禁止跨 feature 直接引用。
src/shared共享 UI、hooks、utils。外部优先走 @shared/public。
scriptsgates/audit/docs/build/maintenance/lib。新增脚本先判断是否阻断式 gate。
