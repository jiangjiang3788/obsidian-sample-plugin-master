发布流程

发布前后按固定流程检查，避免漏步骤。

状态：建议模板 最后更新：2026-05-07 格式：HTML

发布流程

  1. 确认需求和功能验收已完成。
  2. 更新 Changelog 和发布记录。
  3. 运行 npm run check。
  4. 运行 npm run test。
  5. 运行 npm run build。
  6. 在 Obsidian 中手动打开插件验证。
  7. 记录已知问题和回滚方案。
  8. 发布或打包。

发布包应包含

文件说明
manifest.json插件元信息。
main.js构建后的主脚本。
styles.css构建后的样式。
必要文档README 或发布说明。
