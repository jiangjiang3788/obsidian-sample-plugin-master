实施计划：Phase A 类型收尾

这是第二轮工程稳定化实施计划。目标不是继续大重构，而是清空 npm run typecheck:src 暴露的类型债，让 gate、test、build、typecheck 四条验证线全部稳定。

状态：执行中优先级：P0最后更新：2026-05-14

执行目标

本计划只处理类型系统收尾，不做新的功能开发，不继续大规模目录搬迁。验收目标是：

  • npm run typecheck:src 通过。
  • npm run gate 继续通过。
  • npm run test:unit 与 npm run test:integration 继续通过。
  • npm run build 继续通过，并生成可用 main.js。
