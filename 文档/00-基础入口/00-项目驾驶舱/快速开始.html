快速开始

给未来的自己一个最短路径：如何看项目、跑项目、改项目。

状态：建议模板 最后更新：2026-05-07 格式：HTML

第一次打开时

  1. 打开 文档/index.html。
  2. 阅读 项目总览、插件定位、功能地图。
  3. 进入 文件地图 找到要改的模块。
  4. 如果是新功能，先在 需求池 登记。

常用命令

命令用途备注
npm run dev本地开发由 Vite 启动开发构建。
npm run build生产构建构建后同步 main.js 和 styles.css。
npm run check基础检查lint、typecheck、gate。
npm run test运行测试使用 Jest 配置。
npm run gate架构约束检查包含 public、capability、DI、platform 边界等 gate。
npm run docs:index生成文档索引更新 文档/_资源/页面内容索引.js，让文档搜索内容保持最新。

改代码前的 5 步

  1. 在 需求池 确认需求是否存在。
  2. 在 用户场景 写清楚用户场景和入口。
  3. 在 文件地图 找到涉及文件。
  4. 在 决策记录 记录方案或替代方案。
  5. 完成后用 代码结构评审 检查。

本文件夹替换方式

解压后把项目根目录下原来的 文档/ 文件夹整体替换为这份 文档/。旧 docs/ 和 html/ 暂时不依赖，可后续归档或迁移。
